# 풍선리그 공식 웹사이트

이 폴더는 GitHub Pages로 바로 공개할 수 있는 정적 웹사이트입니다.

## 가장 쉬운 공개 방법
1. GitHub에서 새 **Public repository**를 만듭니다. 예: `balloon-league`
2. 이 폴더의 `index.html`과 `style.css`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 배포 소스를 `Deploy from a branch`로 설정하고 `main` / `/(root)`를 선택합니다.
4. 저장 후 잠시 기다리면 `https://사용자이름.github.io/balloon-league/` 형태의 주소로 접속할 수 있습니다.

GitHub Pages는 저장소의 정적 HTML/CSS/JS를 실제 인터넷 웹사이트로 게시할 수 있습니다.
